# Reorienting

You may be told to "reorient" when your session has been idle for some time and the environment has changed in 
some significant way. To reorient, run these substeps:

1. Switch your state to 💫.

2. [Rebase](rebase.md) any worktrees you are working on. This involves checking intermediate commits for salient 
changes. These changes might include changes that make your work moot, or require significant rearchitecting; look 
for such changes carefully.

3. Reconsider the approach to your original brief. Did the environment change in ways that make the original 
approach inappropriate? What needs to be rearchitected? Rebuild whatever you think needs updating. If the initial 
brief is now wrong, moot, or inappropriate, evaluate the right path forward, and brief the user.

4. Select the right option from this list and execute:

 * finish the project to complete the initial brief, first switching your state to 🧱.

 * transition to the [end-of-work rules](end-of-work-rules.md), including squashing and giving the user the 
   synopsis of the work, and switching your state to 🐤 when appropriate.

 * switch to a more appropriate state.
